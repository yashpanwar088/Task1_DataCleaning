# Task 1: Data Cleaning and Preprocessing

## 🧠 Objective
To clean a raw dataset using Python (Pandas), fixing missing values, duplicates, inconsistent formats, and incorrect data types.

## 📁 Dataset
- Original: `customer_data_dirty_large.csv`
- Cleaned: `cleaned_customer_data.csv`

## 🔧 Cleaning Steps
- Removed duplicate rows
- Renamed columns to lowercase with no spaces
- Standardized text values in `gender` and `country`
- Converted `joindate` to datetime format
- Converted `age` and `purchase_amount` to numeric
- Dropped rows with missing important values

## 📌 Tools Used
- Python
- Pandas
- Google Colab
